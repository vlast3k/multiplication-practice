# 🚀 Quick Start Guide - Multiplication Practice App

## Start the App in 3 Easy Steps!

### 1️⃣ Open Terminal
```bash
cd /home/user/projects/multiplication-practice-app
```

### 2️⃣ Start the Server
```bash
cds watch
```

You should see:
```
[cds] - server listening on { url: 'http://localhost:4004' }
```

### 3️⃣ Open in Browser
Navigate to: **http://localhost:4004/com.multiplication.practice/index.html**

---

## 🎮 Quick Demo

### Try These Actions:
1. **Answer a Question**: Click any of the 4 answer buttons
2. **Change Difficulty**: Click Easy, Medium, or Hard at the top
3. **View Progress**: Click "Dashboard" button
4. **Change Avatar**: Click "Profile" → Click the 🦄 emoji → Pick a new one
5. **See Badges**: Check Dashboard or Profile for achievements

## 🎨 What Your Child Will See

### Quiz View (Main Screen)
- Big colorful buttons with numbers
- Question like "7 × 8 = ?"
- Difficulty selector (Easy/Medium/Hard)
- Points counter with ⭐
- Streak indicator with 🔥 (when doing well)

### Dashboard
- Three stat cards (Points, Accuracy, Questions)
- Badge collection with progress bars
- Recent practice sessions with star ratings

### Profile
- Big avatar emoji (tap to change!)
- Name (tap to edit!)
- All personal stats
- Badge collection with descriptions
- Settings toggles
